ONE FOLDER PER JOB

Make a new folder in here for each job you want to quote. Name it
after the address, for example "34 Banksia Ave Croydon".

Put inside it:
  - your phone photos of each room or surface (jpg or png, any names)
  - a file called notes.txt with the client's name, phone, email,
    address and anything they told you: rooms, rough sizes, condition,
    colours, timing.

Then start Claude Code and type:   /quote 34 Banksia Ave Croydon

See the "Example - 12 Wattle St Ringwood" folder for what notes look like.
