You get one submission, and the wrong evidence counts as none.

A chargeback is not one thing. Behind every reason code is one of six allegations, and each is decided on different evidence. Proof of delivery does nothing for "I did not authorise this". Device data does nothing for "it never arrived". Say which allegation you are answering and what you actually hold, and this page assembles the response in the order it gets read, and names what is missing while there is still time to go and get it.

What are they actually claiming?

Shopify will have given you a reason. If you have the network code, type it and the right one will be chosen for you. If the wording is vague, pick by what the customer is really saying, because that is what the evidence has to answer.

02

When is it due?

Use the date showing in your Shopify admin, not the one a guide gave you. The networks allow longer at their own level, but the deadline your processor shows is the one that closes the case, and it cannot be extended.

      Where the mapping comes from.

      The card networks' full rulebooks are not public, so nobody writing about this, including me, is reading the primary source end to end. What follows is what the page is built on, with the vendor material marked as vendor material.

      • Shopify, Resolving a chargeback or inquiry The process, the deadline behaviour, and the fact that a missed deadline closes the case with no appeal.
      • Shopify, Managing chargebacks in the Shopify admin Where the deadline you should actually trust is displayed, and what the evidence form does with what you give it.
      • Shopify, ShopifyPaymentsDisputeEvidence The authoritative list of the fields the evidence form actually has, which is why the response below is grouped the way it is rather than written as a letter.
      • Shopify, Dispute file upload The file rules: accepted types, size and page limits, and the PDF constraints that reject a file quietly.
      • Redo, Chargeback reason codes and the evidence that answers each one Vendor material. Used to cross check the six allegation grouping and the Visa and Mastercard code numbering.
      • Chargeflow, Shopify disputes and chargebacks Vendor material, from a company that sells dispute automation. Used for the deadline ranges and the monitoring ratio point. Read it knowing who wrote it, which goes for this page too.

      Reasonable questions

      Will this win my dispute?

      No idea, and neither does anyone else selling you something in this category. The outcome is decided by an issuing bank against rules you and I cannot read in full. What this page can honestly claim is narrower: a packet aimed at the allegation actually being made, containing the evidence that allegation turns on, in an order a reviewer can follow, beats a pile of screenshots. That is a real edge and it is not a promise.

      Does anything I type leave my computer?

      No. There is no server behind this page. Everything is a lookup table and some string assembly running in your own browser, which you can confirm by opening your network tab, or by turning the internet off before you start. It will keep working. Given you are about to type an order number and a customer's name into something, that seemed like the only defensible way to build it.

      Shopify gave me wording, not a code.

      Common, and it is why the six choices are written as what the customer is claiming rather than as code numbers. Pick the one that matches what they are really saying. If two seem to fit, pick the one that is harder to answer and build for that; a packet that over answers is not penalised, one that answers the wrong thing is.
