# fonts/

Display faces for thumbnails and cards, fetched from Google Fonts:

- `Anton-Regular.ttf` — Anton, by Vernon Adams. SIL Open Font License 1.1.
- `BebasNeue-Regular.ttf` — Bebas Neue, by Dharma Type. SIL Open Font License 1.1.

Both licences permit bundling and use in rendered video and images.
The OFL text is at https://openfontlicense.org. Captions use the
system DejaVu Sans (libass), which is also free.
