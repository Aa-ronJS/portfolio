CLAUDE CODE - MAC SETUP
=======================

What you need
  - macOS 13 (Ventura) or newer
  - An internet connection
  - A Claude account with a paid plan (Pro or Max). Sign up at
    https://claude.ai if you do not have one.

Steps
  1. If you downloaded this as a .zip file, double-click it to unzip it
     first. Open the unzipped folder.

  2. RIGHT-CLICK (or Control-click) "1 - Setup Claude Code.command"
     and choose "Open". A message says the file is from an unidentified
     developer or was downloaded from the internet. Click "Open".

     On newer Macs the message may only offer "Done" or "Move to Bin".
     If so: click Done, open System Settings > Privacy & Security,
     scroll down, click "Open Anyway" next to the file name, then try
     again.

     This warning appears for any small program that is not sold
     through the App Store. You can read the file first: right-click
     it and choose Open With > TextEdit.

  3. A Terminal window opens and tells you exactly what it is about to
     do. Press Return to begin. Setup takes one to three minutes.

     macOS may ask if Terminal can access your Documents folder.
     Click Allow, so the project folder can be created there.

  4. When it finishes there is a "Claude Code" file on your Desktop and
     a folder called "Claude Projects" in your Documents.

  5. Double-click the Desktop file. Your web browser opens so you can
     sign in to your Claude account. After that, follow the file
     called "START HERE.txt" inside your project folder.

What setup does (and does not do)
  - Downloads Claude Code from Anthropic's official address only
    (https://claude.ai/install.sh). Nothing else is installed unless
    you say yes to it when asked.
  - Puts Claude Code in your own user folder. It never asks for your
    administrator password, and will refuse to run if given it.
  - Creates Documents/Claude Projects/My Business with a few starter
    files, and a Desktop launcher.
  - Writes a log to ~/Library/Logs/ClaudeCodeSetupKit/setup-log.txt
  - Stores no passwords. You sign in through your browser.

If double-clicking does nothing
  Open Terminal (search for it with Spotlight), type the word  bash
  followed by a space, drag "1 - Setup Claude Code.command" into the
  window, and press Return.

If something goes wrong
  Run setup again. It is safe to repeat. If it still fails, send the
  setup-log.txt file mentioned above to support.
