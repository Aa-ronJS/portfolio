# Consumer private-label comparison model

The A$30k private-label consumer launch used in `../05-financials.md` as the
"what you are not doing" comparison. Single SKU at A$79, 3.27x landed, A$35
CAC, 20% repeat by month 12, founder unpaid.

    python3 cashflow.py      # 12-month cash flow and accrual P&L
    python3 sensitivity.py   # net profit vs CAC, price, repeat rate, landed cost

Assumptions are the variables at the top of each script.
